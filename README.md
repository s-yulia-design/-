# Сайт профориентолога — инструкция

Статический сайт для GitHub Pages. Основные настройки — в `js/site-config.js`.

## 1. Запуск на компьютере

Откройте папку проекта и запустите локальный сервер (например, расширение Live Server в VS Code/Cursor) или откройте `index.html` через локальный сервер — так корректнее работают пути.

## 2. Имя

`js/site-config.js` → `firstName`, `fullName`.

## 3. Фото

Положите файл в `images/expert/photo.webp` и подключите в `index.html` вместо блока-заглушки (комментарий в разметке hero).

## 4. Контакты

`js/site-config.js`: `email`, `phone`, `telegram`, `whatsapp`, `vk`, `max`. Пустые поля не показываются на сайте.

## 5. Цены

Тексты услуг в `index.html` и страницах услуг. После подтверждения цен замените формулировку «Стоимость зависит от формата и запроса».

## 6. Опыт и показатели

Блок hero: только подтверждённые факты. Дополнительные цифры — с комментарием `<!-- НУЖНО ПОДТВЕРДИТЬ У ЕКАТЕРИНЫ -->`.

## 7–9. Отзывы, кейсы, статьи

Секции отзывов/кейсов/блога скрыты. Добавление — по шаблонам в README и `article-template.html`, папка `articles/`.

## 10. Форма

`formEndpoint` в `js/site-config.js` — URL сервиса (Formspree, Getform и т.д.). **Не храните секретные API-ключи в GitHub** — только публичный endpoint, если сервис так работает.

## 11. Токены

Секреты, приватные ключи и пароли — только в настройках сервиса формы или CI, не в репозитории.

## 12. Яндекс.Метрика

`yandexMetrikaId` в `js/site-config.js`. Если пусто — счётчик не загружается.

## 13. Домен

Сейчас в конфиге: `https://ek-uprof.ru` (предполагаемый домен). Обновите `domain`, `sitemap.xml`, `robots.txt`, canonical при смене.

## 14. sitemap.xml

Добавьте URL каждой новой страницы в `sitemap.xml`.

## 15. GitHub Pages

Settings → Pages → ветка `main`, папка `/ (root)`. Корень репозитория должен содержать `index.html`.

## 16. Проверка на телефоне

После публикации откройте сайт на телефоне или DevTools → режим 320–375 px.

## 17. Откат версии

Ветка `backup/pre-production-pass` или коммиты в GitHub Desktop → Checkout / Revert.

---

**Сайт не готов к полноценному запуску** без реальных контактов, юридических данных оператора и рабочего `formEndpoint`.
