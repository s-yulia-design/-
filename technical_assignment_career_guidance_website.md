# Техническое задание (Промпт) для создания сайта специалиста по профессиональной ориентации

## 1. Общая информация

### Название проекта
Персональный сайт специалиста по профессиональной ориентации / карьерного консультанта.

### Цель сайта
Создать современный, экспертный и конверсионный сайт для:
- привлечения клиентов;
- записи на консультации;
- продажи услуг и программ;
- формирования личного бренда специалиста;
- публикации полезного контента.

### Целевая аудитория
- подростки и школьники;
- студенты;
- взрослые в поиске новой профессии;
- люди в состоянии карьерного кризиса;
- родители подростков;
- специалисты, желающие сменить сферу деятельности.

---

# 2. Основные задачи сайта

Сайт должен:
- вызывать доверие;
- демонстрировать экспертность;
- мотивировать записаться на консультацию;
- быть удобным на мобильных устройствах;
- быстро загружаться;
- иметь современный минималистичный дизайн;
- поддерживать SEO-продвижение.

# 13. Дополнительный AI-промпт для генерации дизайна сайта

Создай современный адаптивный сайт специалиста по профессиональной ориентации. Используй минималистичный стиль, светлую цветовую палитру, мягкие анимации и premium UX/UI. Сайт должен вызывать доверие и мотивировать пользователя записаться на консультацию. Предусмотри блоки: hero, услуги, обо мне, отзывы, кейсы, FAQ, блог, форма записи и контакты. Дизайн должен быть адаптивным для мобильных устройств и SEO-оптимизированным.
